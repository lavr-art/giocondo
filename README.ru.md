# giocondo-vpn

[English](README.md) · **Русский**

Self-hosted панель управления VPN-серверами на [sing-box](https://sing-box.sagernet.org/) с VLESS Reality,
Hysteria2 и WireGuard: лёгкая альтернатива Hiddify Manager, Marzban и 3x-ui для личного использования
и небольших групп.

Панель хранит всё состояние: пользователей, сроки подписок, лимиты трафика, ключи протоколов, ноды и историю трафика.
На каждой ноде работает небольшой агент: он получает конфиг от панели и управляет sing-box. Пользователь получает
одну ссылку подписки, которая работает в Hiddify, Happ, v2rayNG, Karing, sing-box и клиентах Mihomo/Clash.

Полная документация на английском: [README.md](README.md).

## Возможности

- **Протоколы**: VLESS Reality, Hysteria2 и WireGuard, все на sing-box.
- **Единый источник правды**: потерянная нода восстанавливается из панели, у агента нет своей базы данных.
- **Защищённая связь с нодами**: агент сам открывает исходящий gRPC-поток к панели по mTLS с собственным CA.
  На нодах не открывается порт управления, а sing-box продолжает работать с последним конфигом, если панель недоступна.
- **Безопасное применение конфигов**: каждый конфиг проверяется `sing-box check`, применяется атомарно
  и откатывается при ошибке.
- **Учёт трафика** по каждому пользователю, включая WireGuard.
- **Пользователи**: сроки, лимиты трафика, сброс лимита с сохранением истории, продление,
  автоудаление просроченных.
- **Подписки**: base64-ссылки, sing-box JSON (1.12+) или Mihomo YAML — формат выбирается по `User-Agent`
  или `?format=`; заголовки `subscription-userinfo` и профиля настраиваются на странице Settings.
- **Маршрутизация для России**: локальные сети и российские зоны/сервисы — напрямую, заблокированные ресурсы
  и всё остальное — через VPN, на основе [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat).
- **Веб-интерфейс и REST API**: обзор трафика, пользователи у лимита, проблемные ноды; API по OpenAPI
  с токенами разных уровней доступа.
- **Установка нод** по SSH или через cloud-init; DNS-записи в Cloudflare по желанию.
- **Проверка доступности** реальными клиентскими подключениями, с внешней точкой проверки по желанию.
- **Простой запуск**: один Go-бинарник, SQLite без CGO, deb-пакеты для amd64/arm64 из подписанного apt-репозитория.

## Быстрый старт

Панель и нода на одном чистом сервере Debian 11+ / Ubuntu 22.04+ (amd64 или arm64), от root:

```sh
# По IP: HTTPS с IP-сертификатом Let's Encrypt на https://<IP>:8443 (нужен открытый порт 80)
bash <(curl -fsSL https://lavr-art.github.io/giocondo/install.sh)

# С доменом: HTTPS через Caddy и Let's Encrypt на https://vpn.example.com:8443
bash <(curl -fsSL https://lavr-art.github.io/giocondo/install.sh) --domain vpn.example.com

# Обычный HTTP по IP на :8081, если порт 80 открыть нельзя
bash <(curl -fsSL https://lavr-art.github.io/giocondo/install.sh) --http
```

Путь к админке и пароль генерируются при установке:

```sh
grep -E '^PANEL_ADMIN_(PATH|PASSWORD)=' /etc/giocondo-vpn/panel.env
```

Без домена админка открывается через SSH-туннель: `ssh -L 8080:127.0.0.1:8080 root@<IP>`, затем
`http://127.0.0.1:8080<PANEL_ADMIN_PATH>/`. С доменом — `https://<домен>:8443<PANEL_ADMIN_PATH>/`.

Подробнее об установке, дополнительных нодах и настройках — в [README.md](README.md#quick-start).

## Вопросы и ответы

**Какие VPN-клиенты поддерживаются?**
Любые, что импортируют ссылку подписки: Hiddify, Happ, v2rayNG, Karing, sing-box (1.12+) и клиенты Mihomo/Clash,
например FlClash и Clash Verge Rev. Для WireGuard подходит и родное приложение WireGuard.

**Чем отличается от Hiddify Manager, Marzban или 3x-ui?**
giocondo-vpn работает только с sing-box, хранит всё состояние в SQLite панели и общается с нодами через агент,
который сам подключается к панели по mTLS, поэтому на нодах нет открытого порта управления. Это один Go-бинарник
на роль, ставится из deb-пакетов и рассчитан на ноду с 1 CPU / 1 ГБ RAM.

**Можно ли перейти с Hiddify Manager?**
Автоматического импорта нет. Установите панель, добавьте ноды и заново создайте пользователей — у каждого
будет новая ссылка подписки.

**Работает ли с несколькими серверами?**
Да. Одна панель управляет любым числом нод, подписка каждого пользователя включает все включённые ноды.
