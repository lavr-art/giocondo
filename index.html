giocondo-vpn

A self-hosted VPN panel for sing-box nodes with VLESS Reality, Hysteria2 and WireGuard: a lightweight alternative to Hiddify Manager, Marzban and 3x-ui for personal and small-group use.

The panel stores users, subscription terms, traffic limits, protocol keys, nodes and traffic history. A small agent on every node receives its config over an outbound gRPC stream with mTLS, so nodes expose no management port. Users get one subscription link that works in Hiddify, Happ, v2rayNG, Karing, sing-box and Mihomo/Clash clients (FlClash, Clash Verge Rev).

Features

  • VLESS Reality, Hysteria2 and WireGuard on sing-box
  • Validated, atomic config rollout with rollback
  • Per-user traffic accounting, terms, limits and extensions
  • Subscriptions as base64 links, sing-box JSON or Mihomo YAML
  • Routing for Russia: Russian zones direct, blocked resources through the VPN
  • Web UI and OpenAPI REST API with scoped tokens
  • Node installation over SSH or cloud-init, optional Cloudflare DNS
  • Single Go binary, SQLite, signed deb packages for amd64 and arm64

Install

On a clean Debian 11+ or Ubuntu 22.04+ server, as root:

bash <(curl -fsSL https://lavr-art.github.io/giocondo/install.sh)

Options, domains and more nodes: see the README.
