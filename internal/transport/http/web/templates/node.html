New server: cloud-init

When creating the server, paste the file into the user-data field: Hetzner "Cloud config", Vultr "Cloud-Init User-Data", DigitalOcean "User data". On first boot the server installs the agent and ufw with the protocol ports and comes online by itself. The file contains the node private key: the cloud shows user-data in its console. Every download issues a new certificate.

Your own server: over SSH

The password and key are used once and are not stored. Without a fingerprint the host key is accepted on first connection and written to the log.
