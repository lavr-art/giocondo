Settings

Subscriptions

The profile name clients show. Overrides PANEL_SUB_TITLE.

How often clients should refresh the subscription.

Optional. Sent as the Support-Url, Profile-Web-Page-Url and Announce headers to everyone with a subscription; only some clients, such as Happ, show them. Leave a field empty to send nothing.

Mihomo routing

Applies only to clients on Mihomo: FlClash, Clash Verge Rev and others. sing-box and Happ keep the built-in rules.

Rules with MATCH replace the built-in ones, including the private network rules; rules without it go before them. Targets: proxy, auto, DIRECT, REJECT, REJECT-DROP, PASS. Built-in lists can be used by name: geosite-ru-blocked, geoip-ru-blocked, geosite-category-ru, geosite-ru-available-only-inside, geoip-ru.

Avoid GEOSITE and GEOIP: FlClash and Clash Verge Rev use their own geodata, and a category missing from it stops the profile. Use rule-providers instead. Saving does not run Mihomo, so check new rules on a client. Provider addresses are visible to clients.
